# 🚀 CryptoWallet — Hybrid iOS Application (SwiftUI + UIKit)

Современное iOS-приложение для отслеживания курсов криптовалют и анализа исторических графиков с поддержкой офлайн-кэширования и безопасной авторизации. 

Проект разработан с упором на чистую архитектуру, потокобезопасность и гибридную интеграцию классического UIKit в современный стек SwiftUI.

## 🛠 Технологический стек и архитектура
* **Архитектура:** MVVM + Repository Pattern + Dependency Injection (через протоколы).
* **UI Фреймворки:** 
  * **SwiftUI** — основной интерфейс, навигация (`NavigationStack`), анимации (`contentTransition`).
  * **UIKit (Programmatic UI)** — экран авторизации, сверстанный кодом (`NSLayoutConstraint`), интегрированный через `UIViewControllerRepresentable`.
* **Графики:** **Swift Charts** — интерактивные графики исторической цены за 7 дней с отслеживанием жестов (`chartXSelection`).
* **Многопоточность:** **Swift Concurrency** (`async/await`, `@MainActor`, `nonisolated`, кооперативная отмена задач через `Task.isCancelled`).
* **Сеть:** `URLSession` + `URLComponents` + `Codable` (интеграция с CoinGecko REST API).
* **Хранение данных и безопасность:**
  * **SwiftData** — локальное кэширование котировок для мгновенного запуска и работы в офлайн-режиме.
  * **Keychain Services** — аппаратное шифрование и хранение токена авторизации (`kSecAttrAccessibleWhenUnlockedThisDeviceOnly`).
* **Тестирование:** **Swift Testing** (`@Test`, `#expect`) — модульные тесты маппинга моделей и асинхронной логики ViewModel с изоляцией базы данных в оперативной памяти (`isStoredInMemoryOnly`).

## ✨ Ключевые технические решения
1. **Безопасная работа с клавиатурой в UIKit:** Реализовано плавное смещение констрейнтов через `NotificationCenter` и `UIView.animate` без утечек памяти (`[weak self]`, очистка в `deinit`).
2. **Офлайн-первый (Offline-First) подход:** При старте приложение мгновенно отображает данные из SwiftData, параллельно запуская фоновый цикл обновления котировок каждые 30 секунд.
3. **Изоляция зависимостей:** Сетевой слой и хранилище закрыты протоколами (`CryptoNetworkServiceProtocol`, `KeyChainServiceProtocol`), что позволяет подменять их на Mock-объекты при тестировании.

## 🚀 Как запустить проект
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Откройте `CryptoWallet.xcodeproj` в **Xcode 16+** (требуется iOS 17.0 / 18.0+).
3. Нажмите `Cmd + R` для запуска на симуляторе (для тестирования экранной клавиатуры на экране входа нажмите `Cmd + K`).
4. Нажмите `Cmd + U` для запуска Unit-тестов.
